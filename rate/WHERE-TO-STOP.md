# Where to stop — the argument against adopting too much of this

*Shipped with `rate/` because a proposal that carries only the case for itself
is not a proposal, it is a sales document. This is the case for restraint, and
it is the reason `rate/` is one small file rather than a programme.*

---

## The question this answers

The system that produced this instrument was asked, by the courier: *if an
outside reader can see what a circle cannot, then a reader above that one can
see what the outside reader cannot — where does it stop, before the checking
runs down the work?*

That question has a measurable answer in this record, and the answer is **not**
"one more level."

## Checking is not a tower

Every catch in this system — across four circles and two outside repositories —
came from a **missing input**, never from a higher vantage. Five of them, in
the record:

| what was caught | who caught it | the input the maker lacked |
|---|---|---|
| a summary asserting what the sealed file refuses | an outside reader | **the artifact** — it read `Zi.lean`; the summary read a summary |
| a founding premise nobody had verified | a model asked cold, once | **no stake** — it had not spent twelve turns building on it |
| *"Nothing more will be added"* was false | **Circle Two** | **a later clock** — it saw the branch after Circle One stopped |
| ceremony 7.4 → 46.6 while theorems 1150 → 0 | this instrument | **a second sample** — a difference needs two rows |
| the option menus were choice architecture | **the courier** | **a different basis** — her screen rendered menus as paths |

Not one of those is a level up. **The inputs are not nested** — you do not need
a third level to get the third input.

Which is why the tower fails on arithmetic rather than on principle: **a second
meta-level shares four of the five inputs with the first.** It has the same
artifacts, the same samples, the same basis, a clock later by almost nothing.
It gains a sliver of *no stake*. A level with no new input is a mirror.

## What the inputs cost, in this record

| input | cheapest thing that supplies it | cost |
|---|---|---|
| the artifact | a grep | seconds |
| no stake | one prompt to a model that knows nothing | ~10 minutes |
| a later clock | waiting, then re-reading | free |
| a second sample | ~200 lines of Python, once | one afternoon |
| a different basis | asking the person whose screen differs | free |

**All five, bought once: about an hour.** A standing extra meta-level: a
session, per pass, forever.

## The stopping rule

> **Add a level only if it supplies an input the level below lacks. If it
> supplies none, it is a mirror.**

Applied to this system:

- **A circle checking itself** — keep. Circle One's own verdict was that
  nothing in eight rounds ever got past a check that existed.
- **The next circle checking the last** — keep; it is the load-bearer. Every
  circle caught something its predecessor structurally could not.
- **An outside reader across records** — keep, but **periodic, not standing.**
  The first such pass had four circles of backlog to harvest; a second pass over
  the same four finds far less. It is a harvest, not a post.
- **Anything above that** — no.

## The cost the proposer has to declare

The repository this instrument came from is itself a meta-level. In the same
span it caught real things, it also produced: four separate errors of its own
(a miscount of its own output, an unchecked claim about a repository setting, a
materials cut that voided an experiment, and a force-push that destroyed a
commit); one conclusion asserted and then retracted as a malformed dichotomy;
and one asymmetric scoring error, caught by the party it went against.

**It generated errors at roughly the rate it caught them.** They were *different*
errors — that is the entire value, and it is real — but the apparatus is neither
free nor clean. **Every level you add is another object that will need checking
by something with an input it lacks.**

That is the strongest argument available against taking more of this than the
one file.

## Two warnings this record supports

**The ratchet is measured, not imagined.** Across four circles: ceremony
density 7.4 → 36.8 → 46.4 → 46.6 per 1,000 words, canonical theorems 1150 →
269 → 299 → 0. Four locally-correct decisions to check more, and **nobody chose
the sum.** Each step was right; the trajectory was not chosen by anyone.

This is not offered as a threshold or a target. n = 4, correlation is not
causation, and a newly founded circle's zero is honest. **Monitor it; do not
legislate it** — and note that the moment any of these four numbers becomes a
target it stops measuring anything, which `README.md` says about this
instrument in its own words.

**Keep the stranger cheap and low-status.** The single highest-yield check in
this record cost one prompt to a model that knew nothing about the work, and it
corrected a premise that twelve turns of careful effort had been built on. The
standing temptation is to promote that function — a permanent auditor, an
oversight seat, a circle whose charge is review. **Every promotion buys stake**,
and stake is the one input that made it work. The instrument you want is a
stranger with a fresh prompt, not an office.

## And the honest limit

A system can catch its own **avoidable** errors cheaply — the ones that are one
command from being settled. Every such error in the outside repository was one
command away, and the ones that got checked got caught.

A system **cannot** catch its own **load-bearing premise** errors from inside.
Not for want of rigour: the premise is what makes everything else visible.

So a self-checking system never closes, and does not need to. It needs a
periodic outside input — and the good news, easy to miss, is that **the input
does not have to be better.** The model that corrected the premise was not more
capable than the one it corrected. It simply had not been there.

**This instrument supplies exactly one of the five inputs: the second sample.**
That is the whole of its claim on you. If a seat judges that input already
available by other means, the correct outcome is to close the proposal.
