# `interventions/` — the four, and which of them actually bind

*Kelly: "can I just be the external shock and say we are doing this now? If so,
do whatever makes these binding."*

---

## The answer to the shock question, because it changes what "binding" means

**Yes — and you already have, twice today, and neither time needed a mechanism.**

The motion to retire norm 20 was a shock. *Run the control* was a shock. Both
worked, both were events, and **an event does not need to be made binding.** It
happens or it doesn't.

**What you cannot be is the terminal condition.** In every system that persists,
the thing that ends an argument is external *because nobody controls it* — death,
the kernel, the balance, the market. A principal can always change their mind,
which is not a criticism, it is the definition of the role. **A rule enforced by
"Kelly said so" is a permission clause with the sign flipped**, and this record
already convicted that shape: norm 20's own closing note says it was written down
because *"a habit living in one person's head is the exact shape this circle keeps
convicting."*

So the split is clean:

> **The shock is yours and needs no mechanism. The state it leaves behind needs a
> gate, because a state has to survive you not being there.**

And this record has exactly one demonstrated way to make something binding:
**make it runnable.** Norm 16 binds because you can execute it. Circle Four's five
gates still run green on a sealed tree with no seats and no builder. Norm 20 never
bound anything — it blocked.

**Which is why three of these four are shell scripts and the fourth is a thing
only you can do.**

## The four

| # | intervention | how it binds | status |
|---|---|---|---|
| 1 | **Delete permission clauses; keep every action-rule** | `norm_shape.sh` flags them; **the deletion itself is one-time and needs no standing rule** | gate written, self-tested |
| 2 | **Cap what a circle inherits** | `inheritance_budget.sh` — a number, checked mechanically | gate written, self-tested |

Every gate runs `--selftest` (norm 16: fail on a planted defect, pass clean) and
prints **what it cannot catch**, because a gate tested only against the failures
its author imagined certifies the author's imagination.

## What each one does

### `norm_shape.sh` — is this rule an instrument or a permission?

```
$ norm_shape.sh NORMS.md
instrument         norm 17
instrument         norm 18
PERMISSION-SHAPED  norm 20   names: written word of
instrument         norm 19
instrument         norm 21
```

Reproduces the hand census exactly: **twenty of twenty-one are instruments; norm
20 is the only permission clause in the canon.**

**It got that wrong first, and the failure is why it is trustworthy.** The first
version scanned whole norm entries and flagged **four of five** as
permission-shaped, because their provenance sentences say *"Proposed by the
builder."* Attribution, not permission. **Its self-test passed anyway — the
planted defect was the one its author imagined.** SR43's species, committed inside
the instrument written to fix that species. The four false positives are now
probes 3 and 4 in the self-test, and **the gate is only credible because it failed
on real data before it passed on invented data.**

### `inheritance_budget.sh` — a circle may not inherit more than it can contradict

```
$ inheritance_budget.sh the-workshop-circle-five 8000
inherited prose : 18627 words
authored  prose : 12215 words
ratio           : 1.52
OVER BUDGET by 10627 words.
```

**Instruments are exempt and prose is not**, and that asymmetry is the whole
design: **an instrument demands *passing*; prose demands *consistency*.** A gate
does not care whether you agree with it, so a circle can inherit a hundred of them
and stay free. A record demands agreement, and agreement is what novelty has to
be able to withdraw.

**The number is a knob, not a finding.** 8,000 is not derived from anything. Its
only job is to be a number instead of a habit, set by whoever pays.

**The falsifier ships with it:** if a circle inherits 5,000 words instead of
18,000 and its theorem count is still zero, the inheritance story is wrong and
this gate should be deleted rather than tuned.

### `exit_gate.sh` — a sandbox where error is cheap

**A codebase does not run one review standard everywhere.** The release branch
is locked; the scratch branch is not. That works for one reason: nothing on the
scratch branch is load-bearing until it has been rebuilt where things are
load-bearing. **Averaging the two into one middling standard gives neither** —
too strict to try things, too loose to depend on.

Inside `sandbox/` the canon does not apply and a wrong turn costs one wrong
turn. The gate enforces exactly one property, the one that makes that true
rather than aspirational: **the cumulative record may not cite the sandbox.**
Work enters the record by being rebuilt outside, where the canon applies.

**A sandbox the record cites is not a sandbox. It is a second record with a
lower standard.**

### Overlap — the one with no gate

Start circle N+1 one round before circle N closes.

**MEASURED:** ceremony is U-shaped, not a ramp. Circle Four's R0 is 62.5 and its
R8 is 57.8, its two highest. Circle Three's R1 is 54.3 and its post-seal is 56.6.
**A body that knows it is ending optimises for the record, because the record is
the only thing that survives it.**

That is *rational*, which is exactly why no gate can fix it. **You cannot legislate
away a correct response to a real incentive — you remove the incentive.** An
overlapping successor is a live audience instead of an archive.

Only the founder of circles can do this. It is the one intervention that is
genuinely yours, and it is probably the most powerful of the four.

## What none of this establishes

**The evidence is thin and I have said so at every step.** Arm C: n = 21 rounds,
r = −0.507, one arm not blind, a counter-example inside the data, time confounded,
a rival hypothesis that cannot be separated. The inheritance measurement is n = 3
usable with an inconsistent classifier.

**I proposed three drivers in one day — the canon, the terminal condition,
inheritance weight — and each time the previous one survived partially rather than
dying. That is what fitting explanations to n = 4 looks like from the inside, and
it feels like refinement.**

So the claim these gates rest on is **not** that any explanation is right. It is
that **all four interventions are cheap and reversible**, which is a different
property, and the only one this evidence buys. Every gate is one file. Deleting
one costs nothing. **If a circle ever reports a green gate here as an achievement,
delete the gate rather than refining it** — which is what `rate/README.md` says
about itself, and it applies here with more force, because these were written by
the same party in the same week.
